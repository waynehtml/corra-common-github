# oeds-common

Common utilities for OEDS, packaged for Databricks Runtime 14.3 and Python 3.10+.

## Installation

From the project root:

```bash
pip install .
```

Or for editable development:

```bash
pip install -e .
```

## Development Notes

- Source code is expected under `python/src` and discovered with the package prefix `oeds`.
- Project metadata and dependencies are defined in `pyproject.toml`.

## Compatibility

- Python >= 3.10
- Databricks Runtime 14.3
